# ProductionPulse

**Factory Production & Maintenance Management System**

ProductionPulse is a web-based factory equipment and maintenance management application developed using Java, Spring Boot, SQL, HTML, CSS and JavaScript.

## Features

- Register and manage factory machinery.
- Edit existing equipment details and operational status.
- View real-time equipment statistics.
- Create maintenance work orders with priorities and due dates.
- Track maintenance jobs from Open through In Progress to Completed.
- Identify overdue maintenance work orders.
- Search and filter equipment and maintenance records.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- Maven
- H2 SQL Database
- HTML5
- CSS3
- Vanilla JavaScript
- REST APIs

## Running the Application

Ensure a compatible Java JDK and Maven are installed.

Clone the repository and navigate to the project folder.

```bash
mvn spring-boot:run
```

Open your browser at:

http://localhost:8080

## Project Purpose

ProductionPulse demonstrates full-stack Java development, database persistence, REST API design and interactive frontend development within an industrial maintenance management scenario.
